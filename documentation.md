# Documentation technique — Observatoire des revues africaines en libre accès

La documentation technique est [`documentation.html`](documentation.html),
V6.0 du 21 novembre 2026, publiée sur
<https://africanjournals.azilan.me/doc_technique/>.

Ce fichier en était un jumeau Markdown. Deux documents pour un seul sujet, et
c'est le Markdown qui a décroché : resté en V4.1, il décrivait encore l'état de
juin 2026 sur neuf de ses douze sections, ignorait le catalogue des
visualisations et le cache d'enrichissement, et annonçait un cache navigateur de
31 jours là où le code en applique 7. Il est réduit à ce renvoi plutôt que
supprimé, pour que son chemin continue de mener quelque part.

La V4.1 reste lisible dans l'historique git : `git show 00e0116:documentation.md`.
